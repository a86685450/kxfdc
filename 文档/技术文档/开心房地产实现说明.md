# 开心房地产实现说明

## 项目概述

`开心房地产` 是一款竖屏点击放置类盖房子小游戏。玩家点击鼠标左键或触摸屏幕，让吊钩上的正方形房子带着摆动惯性下落，并尽量稳定叠到上一层房子上。

当前项目使用 **Cocos Creator 3.8.8** ，框架和自动化调试链路参考 `/Users/happyelements/zhu/HongHuang`。

项目当前按 `720x1280` 竖屏设计。启动时通过 `GameLauncher` 设置 `ResolutionPolicy.SHOW_ALL`，优先保证完整显示登录界面、底部菜单和游戏地面；当预览窗口比例与设计比例不一致时，边缘可能出现留边。

## 参考内容

- `HongHuang` 的 `UIManager`、`UIBase`、`EventManager` 架构被迁移为当前项目的轻量版 UI 框架。

## 登录界面

登录界面包含 4 个菜单项：

| 菜单项 | 行为 |
|---|---|
| 开始游戏 | 进入普通玩法 |
| 继续游戏 | 当前等同普通玩法，读取最高分展示 |
| 玩法测试 | 进入测试模式并自动盖房子，默认盖到 110 层，间隔 `0.18` 秒 |
| 清空存档 | 清理本地最高分、最高层数和最高连击 |

登录背景使用 `assets/resources/textures/login/login_bg.png`，图片自身包含标题元素，因此界面层已移除旧文字标题和副标题。菜单按钮放在画面底部区域，依赖 `SHOW_ALL` 适配策略保证完整可见。

## 核心玩法规则

偏移百分比计算方式：

```text
偏移百分比 = abs(当前房子中心 x - 摇摆后的目标中心 x) / 房子宽度 * 100%
```

判定规则：

| 偏移百分比 | 结果 | 表现 | 累计偏移变化 |
|---:|---|---|---|
| 第一层 | 成功 | 落到地基，保留真实落点 | 不增加 |
| `<= 5%` | Perfect | 自动吸附，飘字 `perfect` | 减少 |
| `5% - 10%` | Good | 不修正，飘字 `good` | 小幅增加 |
| `10% - 50%` | 普通成功 | 不飘字 | 按偏移增加 |
| `> 50%` | 失败 | 房子倾斜掉落，弹结算 | 游戏结束 |

`Perfect` 的累计偏移减少有保护下限：如果累计偏移曾经超过 `5`，后续通过 `Perfect` 减少后也不会低于 `5`。

第一层房子从真实地面顶部开始盖，地面资源位于画面底部，顶部坐标由 `GameConfig.FOUNDATION_TOP_Y` 控制。楼层变高后恢复为顶部约 `2.5` 层可见的镜头逻辑：楼体按层数整体滚动，背景层按同样的滚动时长移动，移动距离暂定为房子滚动距离的 `3` 倍。

背景控制器采用三层结构：底层用两个 `1.5` 屏高的渐变 Tile 上下拼接并循环复用，每个 Tile 由横向色块模拟“底部到顶部”的自然渐变，下面 Tile 离开屏幕后会移动到另一张 Tile 上方并切到下一段渐变色，最终停在黑色；中层按背景偏移量动态添加城市、月亮、热气球、超人、卫星和行星等装饰；顶层暂时预留给后续云雾、光效或遮罩。

当前背景装饰节奏：

| 楼层区间 | 装饰 | 表现 |
|---:|---|---|
| 低层 | 城市背景 | 底部城市楼群叠加在渐变背景上 |
| 约 30 层 | 月亮 | 固定在高空区域展示 |
| 约 40 层 | 热气球 | 多图随机，缓慢左右摆动 |
| 约 50 层 | 超人 | 从左向右飞过 |
| 约 65 层 | 卫星 | 多图随机，缓慢漂移 |
| 约 80 层后 | 行星 | 太阳系合图切割后按高度逐步随机展示 |

## 自动化测试

点击登录页的 `玩法测试` 后，会进入游戏面板并启动可视化自动盖房子模式，默认盖到 110 层，便于观察背景、地面和高层装饰资源。`GamePanel` 通过定时器调用测试用的强制落房接口，完成后停止计时器。

快速冒烟测试保留在 URL 参数入口。当前覆盖：

- 第一层落地
- `Perfect` 自动吸附
- `Good` 不修正并小幅累加偏移
- 普通成功与 `50%` 内的大偏移成功
- 超过 `50%` 失败
- 超过 5 层后进入楼体摇摆阶段
- 顶部约 `2.5` 层可见
- 镜头上移时背景层按 `3` 倍距离同时间下移
- 底层双 Tile 循环移动并自然渐变到黑色
- 三层背景架构与中层装饰动态添加 / 释放
- 30 层月亮、40 层热气球、50 层超人、65 层卫星和 80 层后行星
- 对象池创建数量受控
- 重新开始时清理失败房子和临时飘字
- 重新开始时初始化背景并清理旧装饰
- 纯规则层阈值验证

测试结果会输出到屏幕底部和浏览器控制台。

也可以通过预览 URL 自动进入测试模式：

```text
http://localhost:7456/?autoTest=1
```

`GameLauncher` 会检测 `autoTest=1` 或 `test=1` 参数，跳过登录面板并直接打开游戏面板执行玩法测试。

可视化自动盖房子也支持 URL 参数：

```text
http://localhost:7456/?autoPlay=1&floors=85&interval=0.05
```

`GameLauncher` 会检测 `autoPlay=1`，并读取 `floors` 和 `interval` 参数控制自动盖房子的目标层数与间隔。
